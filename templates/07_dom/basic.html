Lesson 07-1

DOM の基本

HTML の要素を JavaScript で取得して、文字を読み書きする方法を確認します。

DOM とは

ブラウザは、HTML を読み込むと、タグの入れ子の関係を木のような形で覚えます。 これが DOM（Document Object Model）です。 JavaScript は DOM を通して、ページの要素を探したり、中身を書き換えたりできます。 

<!-- HTML -->
<body>
    <h1 id="title">こんにちは</h1>
    <p>DOM の説明</p>
</body>
// DOM（木の形）
document
 └─ body
     ├─ h1#title  → "こんにちは"
     └─ p         → "DOM の説明"

document は、DOM の入り口になるオブジェクトです。 要素を探すときは、document.○○() の形で呼び出します。

1. getElementById() と textContent

document.getElementById("id名") で、id が一致する要素を1つ取得します。 取得した要素の textContent を使うと、中の文字を読み書きできます。

こんにちは

// id="greeting" の要素を取得
const greeting = document.getElementById("greeting");

function setGreeting(text) {
    greeting.textContent = text;          // 書き換える
}

function readGreeting() {
    const text = greeting.textContent;   // 読み取る
    document.getElementById("greetingLog").textContent = `読み取った文字：${text}`;
}
書き方 意味
document.getElementById("greeting") id が greeting の要素を取得する（見つからないと null）
要素.textContent 要素の中の文字を読み取る
要素.textContent = "文字" 要素の中の文字を書き換える

取得した要素は、const greeting のように変数に入れておくと、何度も使えます。 関数の外で1回だけ取得しておくのが一般的です。

注意: getElementById("Greeting") のように、 id の大文字・小文字が違うと見つかりません。 また、HTML より先に JavaScript が動くと、要素がまだ無いので取得できません。 そのため、<script> は </body> の直前に書きます。

2. textContent と innerHTML の違い

どちらも要素の中身を書き換えられますが、タグの扱いが違います。 textContent はタグもただの文字として表示し、 innerHTML はタグをHTML として解釈します。

textContent

innerHTML

const tagString = "<strong>太字</strong>の文字";

textBox.textContent = tagString;   // → <strong>太字</strong>の文字（そのまま表示）
htmlBox.innerHTML = tagString;     // → 太字の文字（「太字」だけ太くなる）
textContent innerHTML
タグの扱い 文字として表示 HTML として解釈
使いどころ ふつうの文字を表示するとき タグを含む HTML を作るとき
安全性 安全 入力された文字を入れるのは危険

注意: フォームに入力された文字や、外部から受け取ったデータを innerHTML に入れてはいけません。 悪意のあるタグやスクリプトが、そのまま実行されてしまうことがあります（XSS）。 迷ったら、まず textContent を使いましょう。

3. querySelector() と querySelectorAll()

querySelector("セレクタ") は、CSS と同じ書き方で要素を探します。 id 以外にも、クラス名やタグ名で探せます。 最初に見つかった1つを返すのが querySelector()、 見つかったすべてを返すのが querySelectorAll() です。

  • みかん
  • ぶどう
  • もも

見つかった数：

上のリストの HTML は、次のようになっています（見やすいように、見た目用の class は省いています）。 色付きの部分が、セレクタで探す目印です。 

<ul id="fruitList">
    <li class="fruit">りんご</li>   <!-- querySelector(".fruit") で見つかるのは、ここだけ -->
    <li class="fruit">みかん</li>
    <li class="fruit">ぶどう</li>
    <li id="lastFruit" class="fruit">もも</li>   <!-- querySelector("#lastFruit") で見つかる -->
</ul>                                         <!-- querySelectorAll(".fruit") なら、4つすべて -->
// 最初に見つかった1つだけ
const first = document.querySelector(".fruit");
first.style.backgroundColor = "#fde68a";

// 見つかったすべて（forEach で1つずつ処理）
const fruits = document.querySelectorAll(".fruit");
fruits.forEach((fruit) => {
    fruit.style.backgroundColor = "#fde68a";
});
console.log(fruits.length);         // 見つかった数: 4

// id も CSS と同じ # で指定できる
document.querySelector("#lastFruit");
セレクタ 意味 例 見つかるタグ
#lastFruit id が lastFruit の要素 querySelector("#lastFruit") <li id="lastFruit" ...>もも</li>
.fruit class が fruit の要素 querySelectorAll(".fruit") <li class="fruit"> が 4 つ
li li タグの要素 querySelectorAll("li") <li> が 4 つ
#fruitList li fruitList の中の li querySelectorAll("#fruitList li") <ul id="fruitList"> の中の <li> が 4 つ

querySelectorAll() は複数の要素を返すので、 forEach() で1つずつ処理します。 1つしか見つからなくても、結果は複数形（リストのような形）で返ります。

注意: querySelector() で要素が見つからないと null が返ります。 そのまま .textContent などを使うと、エラーになります。

要素を取得する方法の比較

メソッド 探し方 返ってくるもの
getElementById("id名") id（# は付けない） 要素1つ
querySelector("セレクタ") CSS セレクタ 最初の1つ
querySelectorAll("セレクタ") CSS セレクタ すべて（forEach で処理）

id で1つ取得するだけなら getElementById()、 クラスなどで探したり、複数取得したりするなら querySelector() / querySelectorAll() が便利です。
