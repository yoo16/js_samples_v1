変数とは

変数は、データに名前を付けて保存しておく箱です。 箱の名前（変数名）を書くだけで、中のデータ（値）を何度でも取り出して使えます。

データの種類 書き方 例
文字列 " " または ' ' で囲む "コーラ"

※ "150" のように引用符で囲むと、数値ではなく文字列になります。

変数の宣言と代入

変数を作ることを宣言、値を入れることを代入といいます。 = は「等しい」ではなく、右の値を左の変数に入れるという意味です。 

// 宣言と同時に代入（初期化）
var price = 150;

文の終わりには ;（セミコロン）を付けましょう。省略しても動くことが多いですが、付けておくと文の区切りがはっきりします。

再代入

宣言済みの変数には、新しい値を入れ直せます（再代入）。古い値は上書きされて消えます。 再代入するときは var を付けません。 

var itemName = "コーラ";
itemName = "オレンジジュース";  // 再代入

console.log(itemName);  // オレンジジュース

"オレンジジュース"

プログラムは上から順に実行されます。console.log() の位置によって、表示される値が変わることを確認してみましょう。

定数

const で宣言すると定数になり、再代入できなくなります。 税率のように、プログラムの途中で変わってはいけない値に使います。 

const TAX_RATE = 0.1;
TAX_RATE = 0.08;  // エラー: Assignment to constant variable.
キーワード 再代入 用途
var できる 古くからある変数の宣言
let できる 現在主流の変数の宣言
const できない 定数の宣言

名前の付け方

変数名は、中身がわかる英単語で付けます。複数の単語をつなげるときは、書き方のルールに合わせます。

書き方 例 対象
キャメルケース itemName 変数
大文字スネークケース TAX_RATE 定数
  • ・ 使える文字は英数字、_、$
  • ・ 数字から始めることはできない（1item は NG）
  • ・ 大文字と小文字は区別される（price と Price は別物）
  • ・ var や const などの予約語は使えない

変数の値を HTML に表示

document.getElementById() で id を指定して要素を取得し、 textContent に変数を代入すると、その要素の中身が書き換わります。 

<!-- HTML -->
<span id="price"></span>

// JavaScript
document.getElementById("price").textContent = price;
