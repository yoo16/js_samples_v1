Lesson 04-2

関数で料金を組み立てる

小さな関数を組み合わせて、カラオケの料金シミュレーターを作ります。

計算の流れ

ボタンを押すと simulate() が動き、役割ごとに分けた関数を順番に呼び出して料金を求めます。 関数の結果は、1つずつ変数に保存してから次の関数に渡します。 例として「平日・大人2人・120分・ドリンクバーあり・会員」の場合を見てみましょう。

calcTotal() の中では、さらに applyDiscount() と addTax() が呼び出されています。関数の中から別の関数を呼ぶこともできます。

使っている関数の一覧

このサンプルには、JavaScript にあらかじめ用意されているビルトイン関数と、 自分で作るユーザ定義関数の2種類が登場します。

戻り値がない関数は return で値を返さず、画面の表示を変えるなど処理を実行することが目的です。

関数の定義と呼び出し

関数は「材料（引数）を受け取り、結果（戻り値）を返す」ひとまとまりの処理です。 一度定義しておけば、名前を書くだけで何度でも使えます。 

// 定義: 金額を受け取り、税込金額を返す
function addTax(price) {
    return Math.floor(price * (1 + TAX_RATE));
}

// 呼び出し: 戻り値を変数に入れる
let total = addTax(3060);   // 3366

引数が複数ある関数

引数は , で区切って複数渡せます。呼び出すときは、定義と同じ順番で値を並べます。 

function calcRoomFee(people, pricePer30min, minutes) {
    let units = minutes / 30;          // 30分単位の回数
    return people * pricePer30min * units;
}

calcRoomFee(2, 300, 120);   // 2 * 300 * 4 → 2400

順番を間違えて calcRoomFee(300, 2, 120) と書いても掛け算の結果は同じですが、料金と人数の意味が入れ替わってしまいます。引数の名前と順番は必ず確認しましょう。

戻り値を別の関数に渡す

関数の戻り値は値そのものなので、別の関数の引数にそのまま使えます。 内側の関数から順に実行されます。 

// 1つずつ変数に入れる書き方（calcTotal() の中身）
let discounted = applyDiscount(subtotal);   // 3400 → 3060
let total = addTax(discounted);              // 3060 → 3366

// 1行にまとめた書き方（結果は同じ）
total = addTax(applyDiscount(subtotal));

引数の既定値

引数に = 値 を付けると、省略されたときに使う値（既定値）を決められます。 

function applyDiscount(price, rate = 0.1) {
    return Math.floor(price * (1 - rate));
}
コード 結果 説明
applyDiscount(3400) 3060 rate を省略 → 0.1 を使う
applyDiscount(3400, 0.2) 2720 rate を指定 → 20% 引き

Math.floor() は小数点以下の切り捨てです。 割引や税の計算で端数が出たときに、金額を整数に揃えるために使っています。

なぜ小さな関数に分けるのか

すべてを simulate() に書くこともできますが、役割ごとに分けると次のような良い点があります。

良い点 このサンプルでの例
使い回せる 大人・学生・子供の3回、同じ calcRoomFee() を呼び出している
直す場所が1つ 料金改定は getPricePer30min()、税率の変更は TAX_RATE だけを直せばよい
読みやすい 関数名を見るだけで、何を計算しているか分かる
確認しやすい formatYen(1234) のように、1つの関数だけを試せる

関数名は動詞＋名詞（calc〜 / get〜 / apply〜 / format〜）にすると、何をする関数なのかが伝わります。
