繰り返しで作るプルダウンと積立シミュレーター

for 文と while 文で、同じ処理を何度も繰り返す書き方を確認します。

年齢選択プルダウン

0 歳から 100 歳まで、101 個の選択肢をfor 文で作ります。 HTML には <select> だけを書いておき、中身は JavaScript で追加します。 

const minAge = 0;
const maxAge = 100;

// minAge から maxAge まで、1 ずつ増やしながら繰り返す
for (let index = minAge; index <= maxAge; index++) {
    addOptionTag(index);
}
部分 書き方 意味
初期化 let index = minAge 最初に1回だけ実行（カウンタを用意）
条件 index <= maxAge true の間、繰り返す
更新 index++ 1回繰り返すごとに 1 増やす

繰り返しの中で呼ばれる addOptionTag() は、option タグを1つ作って select に追加する関数です。 

function addOptionTag(age) {
    const option = document.createElement('option');   // option タグを作る
    option.value = age;                                   // 選んだときの値
    option.innerHTML = age + ' 歳';                    // 画面に表示する文字
    ageSelect.appendChild(option);                        // select の中に追加
}

// 繰り返しのあと、30 歳を選択状態にする

積立貯金シミュレーター

貯金が目標金額に届くまで、while 文で1か月ずつ計算を繰り返します。 何回繰り返すかが決まっていないときは、for 文ではなく while 文を使います。

let month = 0;
let currentSaving = 0;
let totalInterest = 0;

// 貯金が目標に届くまで繰り返す
while (currentSaving < savingTarget) {
    // 今月の利息 = 貯金額 × 年利 ÷ 12
    const interestEarned = currentSaving * (interestRate / 12);
    totalInterest += interestEarned;                  // 累計の利息
    currentSaving += interestEarned + annualDeposit;  // 利息と積立額を足す
    month++;                                          // 月を数える
}

const years = Math.floor(month / 12);   // 年数
// 残りの月数は month % 12
書き方 意味
while (条件) { ... } 条件が true の間、繰り返す（回数は決まっていない）
a += b a = a + b と同じ（足して代入）
month++ month を 1 増やす
month % 12 month を 12 で割った余り（残りの月数）

注意: while 文は、条件がいつまでも true のままだと止まらなくなります（無限ループ）。 このシミュレーターでは、積立額が 0 だと、貯金も利息も 0 のまま増えません。 そのため、積立額が 0 以下のときは計算を始める前に return で終了しています。

for 文は「回数が決まっているとき」、while 文は「条件を満たすまで」。 迷ったら、何回繰り返すか先にわかるかで選びましょう。
