条件式と分岐

条件によって処理を切り替える、if 文と switch 文の書き方を確認します。

条件式（比較演算子）

2つの値を比べる式を条件式と呼びます。結果は true（成り立つ）か false（成り立たない）のどちらかになります。

演算子 意味 例（price = 500） 結果
== 等しい price == 500 true
< より小さい price < 0 false
> より大きい price > 500 false
>= 以上 price >= 500 true
<= 以下 price <= 500 true
!= 等しくない price != 500 false 
let price = 500;

let a = price == 500;   // true
let b = price < 0;      // false
let c = price >= 500;  // true

= は「代入」、== は「等しいか比べる」です。 書き間違えやすいので注意しましょう。（型まで厳密に比べる === もあります）

if 文

条件式が true のときだけ、{ } の中の処理を実行します。false のときは何もせず、次へ進みます。 

let price = 500;
let money = 1000;
let message = "";

// money が price 以上のときだけ実行
if (money >= price) {
    message = "決済完了";
}

条件式

money >= price

→ true →

実行する処理

"決済完了"

部分 役割
if ( ) ( ) の中に条件式を書く
{ } 条件が true のときに実行する処理を書く

if – else if – else

条件が複数あるときは、上から順にチェックします。最初に true になった { } だけを実行し、残りは飛ばします。 どの条件にも当てはまらないときは else が実行されます。 

let message2 = "";

if (price < 0) {
    message2 = "価格エラー";       // 1. price が 0 未満
} else if (money >= price) {
    message2 = "決済完了";         // 2. money が price 以上
} else {
    message2 = "残高不足";         // 3. それ以外
}
順番 条件 結果
1 price < 0 価格エラー
2 money >= price 決済完了
3 それ以外（else） 残高不足

price = 500、money = 1000 のときは、1 は false、2 が true なので 決済完了 になります。 money や price の値を変えて、結果が変わることを確かめましょう。

switch 文

1つの値が何と等しいかで処理を分けるときは、switch 文が便利です。 case に一致した処理から実行されます。 

// 曜日インデックス（0:日 1:月 2:火 3:水 4:木 5:金 6:土）
let weekday = 4;
let trash = "";

switch (weekday) {
    case 1:   // 月
    case 5:   // 金
        trash = "燃えるゴミ";
        break;
    case 4:   // 木
        trash = "燃えないゴミ";
        break;
    default:
        trash = "回収なし";
}
部分 役割
switch (値) 比べる対象の値を指定
case 値: その値と等しいときに実行する処理
break switch 文から抜ける
default: どの case にも一致しないときの処理

break を書き忘れると、次の case の処理まで続けて実行されてしまいます。 上の case 1: のように処理を書かずに並べると、「月 または 金」の意味になります。

曜日 日 月 火 水 木 金 土
インデックス 0 1 2 3 4 5 6

曜日は 0（日）から 6（土）の番号（インデックス）で表します。 new Date().getDay() を使うと、今日の曜日の番号を取得できます。
