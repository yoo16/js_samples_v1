JSファイルの読み込み

ブラウザは HTML を上から順に解析し、script タグの src 属性で指定された JS ファイルを読み込んで実行します。

hello.html

上から順に解析

→

<script src>

JSファイルを読み込み

→

js/hello.js

プログラムを実行

<!-- hello.js 読み込み -->
<script src="js/hello.js"></script>

※ hello.js は js フォルダにあるため、パスは js/hello.js になります。

hello.js で実行していること

ウィンドウタイトルの変更

document.title = "はじめてのJavaScript";

HTML の <title>Hello JS</title> が、JavaScript によって書き換わります。

コンソール出力

console.log('Hello!');

console.log() の内容は Web ページには表示されず、DevTools の Console タブに表示されます。 変数の値や処理の流れを確認するデバッグで使います。

hello.js には console.error() や console.table() などの例もあります。Console タブで表示の違いを確認してみましょう。

ブラウザキャッシュのクリア

ブラウザは一度読み込んだ JS や CSS を保存（キャッシュ）します。 hello.js を修正して保存しても、キャッシュに残った修正前のファイルが使われ、変更が反映されないことがあります。

コードを修正したのに動作が変わらないときは、まずキャッシュを疑いましょう。開発中は Disable cache にチェックを入れておくと便利です。

ファイルを修正したら保存して、ブラウザを再読み込みしましょう。反映されないときはスーパーリロード！
