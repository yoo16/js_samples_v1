算術演算子

演算子 意味 例 結果
+ 足し算 5 + 2 7
- 引き算 5 - 2 3
* 掛け算 5 * 2 10
/ 割り算 7 / 2 3.5
% 割り算の余り 7 % 2 1
** べき乗 2 ** 3 8 
// 小計金額 = 価格 × 個数
subTotalPrice = price * quantity;          // 500 * 3 → 1500

// 合計金額 = 小計金額 - 割引
totalPrice = subTotalPrice - discount;     // 1500 - 150 → 1350

// 税抜き金額 = 合計金額 / (1 + 税率)
taxWithoutPrice = totalPrice / (1 + TAX_RATE); // 1350 / 1.1

算数と同じく、* と / は + と - より先に計算されます。先に計算したい部分は ( ) で囲みます。totalPrice / 1 + TAX_RATE と書くと「1350 ÷ 1 + 0.1」になってしまいます。

インクリメントとデクリメント

++ は変数の値を 1 増やす（インクリメント）、-- は 1 減らす（デクリメント）演算子です。

三項演算子

四捨五入: toFixed()

1350 ÷ 1.1 は 1227.2727… と割り切れません。 toFixed(桁数) は、指定した小数点以下の桁数で四捨五入します。toFixed(0) なら整数になります。 

taxWithoutPrice = Number(taxWithoutPrice.toFixed(0));

toFixed() の結果は文字列です。このあと tax = totalPrice - taxWithoutPrice と計算に使うので、Number() で数値に変換しておきます。

数値の計算と文字列の連結

+ は、数値どうしなら足し算、文字列が含まれると連結になります。 テーブル番号 3 と注文番号 20341 からオーダーコードを作ってみます。

コード 結果 説明
3 + 20341 20344 数値の足し算
"3" + "20341" "320341" 文字列の連結
3 * 100000 + 20341 320341 桁をずらして足す（数値）
`${3}-${20341}` "3-20341" テンプレートリテラル（文字列） 
// 数値のまま連結: 3 を 100000 倍して 5 桁ずらす
var orderCode = tableNo * 100000 + orderNo;  // 320341

// テンプレートリテラルで xx-xxxx 形式の文字列に
orderCode = `${tableNo}-${orderNo}`;          // "3-20341"

テンプレートリテラルは ` `（バッククォート）で囲み、${変数} の部分に変数の値が埋め込まれます。 レシートの `¥${price}` も同じ書き方です。

ブラウザキャッシュのクリア

コードを修正、保存したのに動作が変わらないときは、まずキャッシュを疑いましょう。

ブラウザは一度読み込んだ JS や CSS を保存（キャッシュ）します。 JSファイルを正しく修正して保存しても、キャッシュに残った修正前のファイルが使われ、変更が反映されないことがあります。
