HOW IT WORKS

このページの仕組み

上のトップ画面では、JavaScript が DOM を操作して、
キャッチコピーを1文字ずつ表示し、背景画像を切り替えています。

01

キャッチコピーを1文字ずつ表示する

文字ごとに span タグを新しく作り、キャッチコピーの要素へ追加します。 これを 0.2 秒ごとに繰り返すと、文字が順番に現れます。 

// 1. span タグを作る
let span = document.createElement("span")

// 2. span に index 番目の文字を入れる
span.textContent = text[index]

// 3. span にクラスを追加する
span.classList.add("fade-in")

// 4. 見出し(h1)の中にキャッチコピー(span)を追加する
copyElement.appendChild(span)

// 5. 0.2 秒後に、次の文字へ (displayNextChar を呼ぶ)
setTimeout(() => displayNextChar(), 200)
書き方 やること
createElement("span") 新しいタグを作る（まだ画面には出ない）
textContent タグの中の文字を設定する
classList.add() class 名を追加する
appendChild() 親の要素の最後に追加する（ここで画面に出る）
setTimeout(コールバック, 時間) 時間（ミリ秒）が過ぎてから、コールバック（実行する関数）を1回だけ実行する。200 = 0.2 秒

実行後の HTML

最初の <h1 id="copy"> は空っぽです。 0.2 秒ごとに span タグが1つずつ追加されて、最後は文字の数（11 個）だけ span が並びます。 DevTools の「Elements」タブで、タグが増えていく様子を確認できます。

実行前

<h1 id="copy"></h1>

0.2 秒後（2文字目まで）

<h1 id="copy">
    <span class="fade-in">日</span>
    <span class="fade-in">常</span>
    <!-- 次の文字が追加されていく -->
</h1>

すべて実行後（11 文字）

<h1 id="copy">
    <span class="fade-in">日</span>
    <span class="fade-in">常</span>
    <span class="fade-in">に</span>
    <span class="fade-in">、</span>
    <span class="fade-in">純</span>
    <span class="fade-in">白</span>
    <span class="fade-in">の</span>
    <span class="fade-in">余</span>
    <span class="fade-in">白</span>
    <span class="fade-in">を</span>
    <span class="fade-in">。</span>
</h1>
02

背景画像をフェードで切り替える

画像を先に読み込んでおき、読み込みが終わったら、今の画像を透明にしてから新しい画像に差し替えます。 これを 5 秒ごとに繰り返します。 

// 次の画像のインデックス（最後の次は 0 に戻る）
imageIndex = (imageIndex + 1) % images.length

// 画像を先に読み込む
let image = document.createElement('img')
image.src = images[imageIndex]

image.onload = () => {
    // 今の画像を透明にする
    backgroundImage.style.opacity = 0

    setTimeout(() => {
        // 画像を差し替えて、表示する
        backgroundImage.src = images[imageIndex]
        backgroundImage.style.opacity = 1
    }, 1000)
}

// 5 秒ごとに繰り返す
setInterval(switchBackground, 5000)
書き方 やること
% images.length 余りを使って、0 → 1 → 2 → 0 とぐるぐる回す
image.src 画像のファイルを指定する（読み込みが始まる）
image.onload 読み込みが終わったときに実行する処理
style.opacity 透明度を変える（0 = 透明、1 = 表示）
setInterval(コールバック, 時間) 時間（ミリ秒）ごとに、コールバック（実行する関数）を何度でも実行する。5000 = 5 秒

実行後の HTML

背景の <img> タグは、最初から HTML にあります。 JavaScript はタグを増やさず、src と style の属性を書き換えるだけです。 DevTools の「Elements」タブで、属性が変わる様子を確認できます。

実行前（src なし）

<img id="background-image"
     class="absolute inset-0 ... opacity-0 transition-opacity duration-1000"
/>

読み込み完了直後

<img id="background-image"
     class="absolute inset-0 ... opacity-0 transition-opacity duration-1000"
     style="opacity: 0"
/>

1 秒後（画像を差し替え）

<img id="background-image"
     class="absolute inset-0 ... opacity-0 transition-opacity duration-1000"
     src="images/cafe-2.avif"
     style="opacity: 1"
/>

5 秒後は cafe-3.avif、その次は cafe-1.avif と、src だけが入れ替わります。 1 文字目の表示のあとに最初の切り替えが起きるので、最初に出る画像は cafe-2.avif です。

ゆっくり消えて現れるのは、HTML の transition-opacity duration-1000 が、 opacity の変化を 1 秒かけて動かしているからです。JavaScript は値を変えるだけで、アニメーションは CSS が担当します。
